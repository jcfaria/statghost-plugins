SUMMARY
-------
Built statghost-vscode v0.1.0: a VS Code / Cursor extension that mirrors the
CudaText STATghost chrome contract (ACTION_KEYS, NESTS, grid_plan, protocol)
in TypeScript, with an activity-bar analytic panel, nested editor-title
submenus, Command Palette entries, settings, and a clipboard bridge to
STATghost.

HOW TO INSTALL
--------------
Requires Node.js 20+ (NOT installed on lab machine at build time).

  cd plugins/vscode
  npm install
  npm run compile
  npm install -g @vscode/vsce
  npm run package
  code --install-extension statghost-vscode-0.1.0.vsix

Development (no VSIX):
  Open plugins/vscode in VS Code → F5 (Run Extension).
